Informasi Sistem

Penjelasan model, variabel, dan panduan penggunaan aplikasi

Tentang Aplikasi

NafasKota menampilkan prediksi indeks ISPU PM2.5 satu sampai tujuh hari ke depan pada 5 stasiun pemantauan kualitas udara DKI Jakarta. Prediksi dihasilkan oleh model XGBoost yang hyperparameter-nya dioptimasi menggunakan Particle Swarm Optimization, lalu dibandingkan dengan hyperparameter bawaan dan hyperparameter hasil Random Search.

Cara Kerja Sistem

Model dilatih terlebih dahulu di luar aplikasi menggunakan data 24 Januari 2024 sampai 8 November 2025. Hasil pelatihan disimpan sebagai 7 berkas model, satu untuk setiap horizon: model t+h memprediksi PM2.5 hari ke-h berdasarkan kondisi hari ini. Aplikasi hanya memuat berkas tersebut dan melakukan inferensi, sehingga tidak ada proses pelatihan ulang saat aplikasi digunakan.

Panduan Penggunaan

  1. Buka halaman Dashboard dan pilih stasiun. Mode Aktual menampilkan prediksi 7 hari ke depan dari kondisi terakhir dataset, ringkasan kelima stasiun, dan peta lokasi.
  2. Pilih Mode Simulasi, geser nilai variabel spasial, meteorologi, dan polutan, lalu klik Prediksi untuk membandingkan hasilnya dengan mode aktual. Hasil simulasi bukan prediksi kondisi sebenarnya. Tombol Kembalikan ke nilai aktual mengisi semua slider dengan kondisi terakhir.
  3. Buka halaman Data Historis untuk menjelajahi PM2.5 harian dataset: saring stasiun, rentang tanggal, dan kategori ISPU, ubah tampilan harian/mingguan/bulanan, lalu unduh data terfilter.
  4. Buka halaman Evaluation, pilih stasiun dan tanggal acuan pada periode uji, lalu klik Prediksi untuk membandingkan prediksi dengan nilai aktual. Bagian Jelajahi Prediksi Data Uji menyaring seluruh prediksi periode uji; bagian bawah menampilkan metrik seluruh data uji, perbandingan metode optimasi, kontribusi variabel, dan pengaruh variabel spasial.
  5. Masuk atau daftar akun untuk memakai Unggah Data: unduh template, isi data harian terbaru, lalu unggah untuk mendapat prediksi 7 hari; file minimal 11 hari juga membuka tab Validasi. Halaman Profil menampilkan info akun, ubah nama, ganti password, dan riwayat unggahan selama sesi.

Unggah Data

Prediksi PM2.5 tujuh hari ke depan dari data terbaru yang Anda unggah
Data yang diunggah hanya dipakai selama sesi ini di memori aplikasi. Data tidak disimpan dan tidak menimpa dataset maupun model aplikasi (folder data/ dan models/). Menutup atau memuat ulang halaman akan menghapusnya.
Langkah 1 · Unduh Template Excel
Isi template dengan data harian terbaru. Ketentuan:
  • Kolom: tanggal, stasiun, 6 polutan (indeks ISPU), dan 7 meteorologi.
  • Minimal 4 hari berturut-turut per stasiun; boleh sebagian stasiun saja.
  • PM2.5 wajib terisi pada 4 hari terakhir; meteorologi wajib pada hari terakhir; polutan lain boleh kosong.
  • Kepadatan penduduk & luas RTH tidak perlu diisi.
  • Untuk tab Validasi (prediksi vs aktual), unggah minimal 11 hari berturut-turut.
